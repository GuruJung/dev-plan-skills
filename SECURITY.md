# Security Policy

Security fixes are maintained on the latest version of `main`.

To report a vulnerability, use **Security > Report a vulnerability** in this
repository to contact the maintainer privately. Include reproduction steps,
the affected version, and the potential impact. Do not include vulnerabilities
or credentials in public issues or pull requests.

Use a GitHub-provided `noreply` address for commits. Use `~`, `$HOME`, or
repository-relative paths in examples instead of a personal absolute home path.
Keep local credentials and private configuration out of tracked files.

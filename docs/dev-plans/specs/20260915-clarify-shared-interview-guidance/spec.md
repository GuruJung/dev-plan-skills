표준 기능과 목표 루프 모두 native Plan 모드의 조사·인터뷰를 사용하고, 목표 루프의 항목은 추가 확정 사항이라는 점을 명확히 한다.

- 공통 인터뷰 원칙을 표준 기능 전용 섹션에서 두 유형에 공통으로 적용되는 앞부분으로 옮긴다.
- 유형별 항목이 질문 범위를 제한하지 않는다고 명시한다.
- 목표 루프의 측정·예산·checkpoint 계약은 유지한다.

**Current Spec Impact:** `No change`. 현재 명세가 이미 규정한 공통 native Plan 인터뷰 원칙을 명확히 표현하는 수정이다.

**사용자 결정 사항**

| 주제 | 선택 | 이유·tradeoff | 적용 범위 |
|---|---|---|---|
| 공통 인터뷰 안내 | 앞부분으로 이동하고 질문 범위를 제한하지 않음을 명시 | 목표 루프에서도 native 인터뷰가 적용되는지 혼동 해소 | create-dev-plan 한·영 대응본 |

**승인 기준:** 두 유형 모두 공통 인터뷰 원칙을 적용받는다고 명확하게 읽히고, 목표 루프의 추가 계약과 한·영 의미·강도가 보존된다.

# AGENTS.md 영문화

## 요약

GitHub의 다양한 독자가 저장소 작업 지침을 이해할 수 있도록 `AGENTS.md` 전체를 자연스러운 영어로 번역한다. 기존 규칙의 의미, 강도와 에이전트 동작은 변경하지 않는다.

## 요구사항과 제외 사항

- 제목과 모든 설명 문장을 영어로 번역한다.
- 명령, 경로, 식별자, enum 값, YAML/JSON 키, Git 상태 값은 원형을 유지한다.
- README와 스킬 번역의 원본 선정, 예상 밖 변경 시 중단, 검증 및 설치 안전 규칙을 빠짐없이 보존한다.
- “사용자가 다른 언어를 요청하지 않으면 한국어로 대화·계획·상태 보고”하는 기존 동작 규칙도 영어 문장으로 그대로 유지한다.
- `AGENTS-ko.md`나 별도의 동기화 상태·스크립트는 만들지 않는다.
- README, 스킬 동작, 설치 산출물 및 공개 명령은 변경하지 않는다.
- 번역 과정에서 원문의 모호함을 임의로 해석해 새 정책을 추가하거나 기존 정책을 약화하지 않는다.

## Current Spec Impact

No change. 이번 작업은 저장소 지침의 표시 언어만 바꾸는 순수 번역이다. 현재 워크플로 및 사용자 문서 의도, 기본 대화 언어와 모든 안전 규칙을 보존하며 `docs/dev-plans/current-spec.md`는 수정하거나 번역하지 않는다.

## 사용자 결정 사항

| 주제 | 사용자 결정 | 이유·tradeoff | 적용 범위 |
|---|---|---|---|
| `AGENTS.md` 언어 | 전체를 영어로 제공한다. | 다양한 GitHub 독자가 이해하기 쉽게 하기 위해서다. | 저장소 작업 지침 |
| 실제 언어 정책 | 기본 한국어 대화·계획·보고 규칙을 유지한다. | 동작은 바꾸지 않고 문서 표현만 영어로 바꾸기 위해서다. | 에이전트 동작 |
| 한글 대응본 | 영문 `AGENTS.md`만 유지한다. | 별도 이유는 제시하지 않았다. | 파일 구성과 유지보수 |

## 승인 기준

- `AGENTS.md`의 서술 텍스트가 모두 자연스러운 영어이며 한글 문자가 남지 않는다.
- 기존 모든 규칙을 항목별로 대조했을 때 의미 누락, 강도 약화 또는 동작 변경이 없다.
- 명령, 경로, 식별자와 Git 상태 값이 원문과 동일하다.
- 관련 테스트가 영문 계약을 검사하며 한국어 문구에 의존하지 않는다.
- 모든 eval이 통과하고 독립 리뷰에서 P0–P2 finding이 없다.
